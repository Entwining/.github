Use SVG for websites, documentation, and large displays. Use PNG when a platform requires a bitmap. The PNG files are exports of the same SVG artwork; their size suffixes give the width and height in pixels.

The marks have transparent backgrounds. The avatar includes a warm white background and padding. Upload the square avatar and let the destination platform crop it.

For GitHub, use the [2048-pixel avatar](avatar/entwining-avatar-2048.png). It meets GitHub's [profile picture requirements](https://docs.github.com/en/account-and-profile/reference/profile-reference#profile-picture-requirements). The 4096-pixel avatar exceeds GitHub's dimension limit.

The palette is forest green (`#214B3C`), sage (`#6D9E84`), and warm white (`#F6F3EC`). The monochrome mark uses near-black (`#212127`). Keep the supplied colors, proportions, and spacing.
